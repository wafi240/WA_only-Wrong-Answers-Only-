# 🚀 WA_Only

> **One Platform. One Login. Everything for Competitive Programming.**

WAOnly is a **terminal-based competitive programming platform** built entirely in **C++17** as a Data Structures & Algorithms course project.

Instead of switching between multiple competitive programming websites and tools, WAOnly brings their core experiences together into a single offline application.

---

# 🎯 Vision

Competitive programmers commonly use several different platforms:

* **Codeforces** for contests and ratings
* **Virtual Judge** for practice contests
* **CPH Extension** for coding workflow
* **CodeFetch** for viewing accepted solutions
* **CF Analytics** for profile insights
* **Ultimate Topic List** for structured learning

Our goal was to build **one platform** that combines the core functionality inspired by these tools while demonstrating how classic Data Structures and Algorithms power real software systems.

> **WAOnly is an educational project inspired by these platforms. It is not affiliated with or intended to replace them.**
